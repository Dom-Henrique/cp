## 📖 About Competitive Programming

Competitive Programming (CP) is a mind sport that involves solving well-defined computational problems by applying logical reasoning, mathematical concepts, algorithms, and data structures.

Participants are given a problem statement describing a particular challenge, along with its input and output requirements. The goal is to develop an efficient solution that produces the expected results while respecting the problem's constraints, particularly **time and memory limits**.

Beyond writing code that works, competitive programming encourages us to think about algorithmic efficiency, problem-solving strategies, and the trade-offs between different approaches. It is also an excellent way to strengthen programming skills, develop logical thinking, and become familiar with fundamental computer science concepts.

## 🚀 Getting Started

To clone this repository, run the following command in your terminal:

```bash
git clone https://github.com/Dom-Henrique/cp.git
```

Navigate to the repository directory:

```bash
cd cp
```

You can then explore the platform directories and compile the solutions using a C++ compiler.

For example, using `g++`:

```bash
g++ -std=c++17 -O2 -Wall solution.cpp -o solution
```

Run the compiled program:

```bash
./solution
```
