Resolving questions from competitive programming plataforms, like Codeforces and Leetcode using mainly C++.

## What is Competitive Programming?

It's a mental sport focused into resolve logical problems applying algorithms and data structures, generally in C++, to generate an output. 
The contestants have one paper with problem description and requested outputs. Your task it's develop a solution that don't consume a estabilished memory and time limit.
